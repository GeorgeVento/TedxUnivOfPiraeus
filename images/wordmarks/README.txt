BRAND WORDMARKS — hand-lettered section titles
==============================================

Drop the artwork here using EXACTLY these filenames. The site already
references them; until a file exists the page quietly falls back to a plain
text heading, so nothing ever looks broken.

  host.png              "HOST"             → Un-rushed › line-up › Hosts
  backstage-hosts.png   "BACKSTAGE HOSTS"  → Un-rushed › line-up › Backstage Hosts
  speakers.png          "SPEAKERS"         → Un-rushed › line-up › Speakers
  performance.png       "PERFORMANCE"      → Un-rushed › line-up › Performances
  workshops.png         "WORKSHOPS"        → Agenda › Workshops
  activities.png        "ACTIVITIES"       → Agenda › Activities
  get-tickets.png       "GET TICKETS →"    → Un-rushed › closing CTA
  unrushed.png          the "UNRUSHED" lockup → Un-rushed hero + poster,
                                                 and the home page theme block

FORMAT
  SVG is best (stays razor sharp at any size) — if you have SVGs, save them
  as .svg and tell me, it's a one-line change to switch the extensions.
  Otherwise PNG with a TRANSPARENT background, at least 3x the size it will
  be shown (roughly 1600px wide for the long ones) so it stays crisp on
  retina screens.

  Do NOT bake the yellow halftone into the file — the page already paints
  that behind the lettering. Transparent background keeps the artwork usable
  on any section.

SIZING
  Don't worry about matching sizes between files. The CSS scales every
  wordmark to a consistent cap-height and shrinks the long ones to fit on
  narrow phones automatically.

BACKGROUND TEXTURE (not a wordmark — goes in images/unrushed/ instead)
  halftone-bg.png → the large yellow halftone texture
